# FieldOps Pro — Construction & Field Management

A full-stack portfolio project demonstrating construction field management through Web and React Native mobile applications.

## Watch the Complete Demo

**[Watch or Download the FieldOps Pro Portfolio Video](https://github.com/gssp51/FieldOpsPro-Portfolio/releases/tag/V1.0.0)**

The narrated demonstration covers authentication, project management, daily construction reporting, photo management, and Web-to-Mobile integration.

## Technology Stack

- **Mobile:** React Native (JavaScript)
- **Web:** ASP.NET Core
- **Backend:** C# / ASP.NET Core Web API
- **Database:** Microsoft SQL Server
- **Authentication:** Token-based authentication and role-based permissions
- **Development Tools:** Visual Studio Code, Git

## Professional Experience

I have over 10 years of software development experience, including approximately eight years at The Conco Companies.

My work included construction field reporting, Toolbox Talks, safety incident reporting, jobsite and equipment inspections, equipment inventory, barcode scanning, digital signatures, and payroll-related applications.
